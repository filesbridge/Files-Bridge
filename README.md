# File Bridge

Локальный файловый мост между телефоном и компьютером через Termux и Flask.

Скрипт поднимает простой веб-сервер на телефоне. Ты загружаешь файл через браузер телефона, раздаёшь Wi-Fi точку доступа, подключаешь к ней компьютер и скачиваешь файл через тот же веб-интерфейс, открытый уже на компьютере.

## Возможности

- Загрузка файлов с телефона через обычный проводник браузера
- Список всех загруженных файлов с возможностью скачивания
- Удаление файлов прямо из веб-интерфейса

## Установка

Установи Python и Flask в Termux:

```
pkg install python
pip install flask
```

Скопируй файл `file_bridge.py` в удобную директорию на телефоне, например `~/downloads`.

## Запуск

```
python file_bridge.py
```

При старте сервер выведет в консоль два адреса, например:

```
* Running on http://127.0.0.1:8000
* Running on http://192.168.43.1:8000
```

Первый адрес — только для самого телефона. Второй — для устройств в той же локальной сети, включая компьютер.

## Порядок использования

1. Запусти скрипт на телефоне.
2. Открой на телефоне `http://127.0.0.1:8000` и загрузи нужный файл.
3. Включи раздачу точки доступа Wi-Fi с телефона.
4. Подключи компьютер к этой точке доступа.
5. Открой на компьютере адрес из консоли, который **не** `127.0.0.1` (обычно `192.168.43.1:8000` или `192.168.49.1:8000`).
6. Найди файл в списке и нажми «Скачать».

Если консоль с адресами не видна, IP телефона можно узнать со стороны компьютера: посмотреть основной шлюз сети, к которой он подключён (`ipconfig` на Windows, `ip route` на Linux, `netstat -rn` на macOS).

## Удаление файлов

Рядом с каждым файлом в списке есть кнопка удаления. Перед удалением запрашивается подтверждение. Удаление ограничено папкой `uploads` — выйти за её пределы через путь к файлу невозможно.
